Testing & quality assurance

Testing application behavior and validating fixes

Testing is an important part of application support and implementation. My experience includes manual testing and checking application workflows as part of issue investigation, configuration, updates and implementation support.

Functional testing

Check whether application features and business workflows behave as expected based on the requirement or reported issue.

  • Understand the expected result and reproduce the steps.
  • Compare actual behavior with expected behavior.
  • Record clear steps and observations for follow-up.

Retesting fixes

Verify a reported issue after a fix, configuration change or update has been applied.

  • Repeat the original steps that triggered the issue.
  • Confirm the reported problem no longer occurs.
  • Check related workflows where appropriate.

Regression and workflow checks

Perform relevant checks around connected features after a change, to help identify unintended side effects.

  • Check related modules and key user workflows.
  • Validate important inputs, outputs and status changes.
  • Record any new or recurring issues.

Database and report validation

Use SQL and record comparisons to help confirm whether application output aligns with stored data and expected business rules.

  • Compare selected records and totals.
  • Check for missing, duplicate or unexpected values.
  • Revalidate results after approved corrections.

How I work

A structured approach to troubleshooting

1. Understand

Clarify the symptoms, expected behavior, affected users, timing and business impact.

2. Investigate

Check reproducibility, workflow steps, logs, configuration and relevant records. Gather evidence before changing data.

3. Resolve safely

Coordinate with the appropriate owner, obtain required approval for data changes, and follow the applicable change process.

4. Validate and document

Recheck the affected records and application output, confirm the outcome with the user, and document findings or follow-up actions.
